# Security policy / Política de segurança

## Supported versions

Only the latest published version of the repository (the `main` branch and the data standard version in `docs/SPEC.md`) receives fixes.

## Reporting a vulnerability

**EN.** Please report privately, not in a public issue: a flaw in the validation scripts or workflows (for example code execution through a pull request, a leaked token), personal data published by mistake that needs urgent action, or a compromised site. Use the repository's **Security tab, "Report a vulnerability"** (GitHub private vulnerability reporting / security advisories). A secondary public contact is listed in `docs/PRIVACIDADE.md`. We aim to acknowledge within 5 business days. The project keeps no secrets: the validation workflow runs without keys and with read-only permission.

**PT.** Relate em privado, não numa issue pública: falha nos scripts de validação ou nos workflows (por exemplo execução de código por pull request, vazamento de token), dado pessoal publicado por engano que exija ação urgente, ou site comprometido. Use a **aba Security, "Report a vulnerability"** do repositório (relato privado do GitHub). Um contato público secundário está em `docs/PRIVACIDADE.md`. Meta de confirmação: 5 dias úteis.

## Personal data removal / Remoção de dados pessoais

Use the "Request removal" issue form (without writing personal data in it) or a private report as above. Timelines are in `docs/SPEC.md`, section 8. / Use o formulário "Pedir remoção" (sem escrever dados pessoais nele) ou o relato privado acima. Prazos: `docs/SPEC.md`, seção 8.
